4주차 내용 정리
1. 핵심 개념 
- IP 주소: 네트워크상에서 장치를 식별하는 주소 (127.0.0.1은 내 컴퓨터 자신)

- 포트 (Port): 컴퓨터 안에서 실행 중인 특정 프로그램을 구분하는 번호

- DNS: 도메인 이름을 IP 주소로 변환해 주는 역할


2. 주요 네트워크 명령어

- ip addr: 내 컴퓨터의 IP 주소 확인

- ping: 상대 컴퓨터와 통신(응답) 여부 확인

- dig: 도메인의 IP 주소(DNS) 조회

- curl: 터미널에서 웹 서버로 HTTP 요청 전송 및 확인

- ss -tlnp: 현재 열려 있는 TCP 포트와 프로세스 확인
